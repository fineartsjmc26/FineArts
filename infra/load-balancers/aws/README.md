AWS ALB (Terraform example)

Overview
- Terraform sample to create an Application Load Balancer, target group, listener and health check.

Requirements
- Terraform installed
- AWS credentials configured (AWS CLI or environment variables)

Files
- `aws-alb.tf` — example Terraform resources (placeholders must be replaced).

Deploy
```bash
cd infra/load-balancers/aws
terraform init
terraform apply
```
