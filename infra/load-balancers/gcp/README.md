GCP HTTP(S) Load Balancer (Terraform example)

Overview
- Terraform sample to create a global HTTP(S) Load Balancer in front of instance groups or backend services.

Requirements
- Terraform installed
- GCP project with APIs enabled

Files
- `gcp-lb.tf` — example Terraform config (placeholders must be replaced).

Deploy
```bash
cd infra/load-balancers/gcp
terraform init
terraform apply
```
